# MAN’GO DANCE

Адаптивный демо-сайт школы танцев в Строгино.

## Просмотр

Откройте `dist/index.html` в браузере или запустите любой статический HTTP-сервер с корнем `dist/`.

Опубликованное демо: https://mango-dance-demo-tanya.brownmoose4096.chatgpt.site

## Структура

- `dist/index.html` — страница сайта.
- `dist/style.css` — основное оформление.
- `dist/compact.css` — компактные мобильные карточки, стрелки и закреплённая шапка.
- `dist/app.js` — расписание, выбор направления, ссылки записи и прокрутка карточек.
- `dist/assets/` — сгенерированные изображения.
- `IMAGE-PROMPTS.md` — описание изображений.

Сборка и зависимости не требуются. Шрифт Manrope загружается из Google Fonts, при недоступности используется системный шрифт.
